# Week 3 — Dynamic Programming

**Objective:** The category candidates fear most. Build real pattern recognition (not memorized solutions) across the common DP shapes.

## Daily Drill
- **Day 1:** 1D DP — 5 problems (climbing stairs, house robber, coin change).
- **Day 2:** 2D DP — 5 problems (unique paths, longest common subsequence, edit distance).
- **Day 3:** Knapsack pattern — 5 problems (0/1 knapsack, partition equal subset sum).
- **Day 4:** String DP — 5 problems (longest palindromic subsequence, word break).
- **Day 5:** DP on trees/graphs — 5 problems (house robber III, longest increasing path in matrix).
- **Day 6-7:** Mixed review set (10 problems, timed) + practice explaining recurrence relations out loud.

## Daily Interview Questions
1. How do you recognize a problem is DP before you start coding?
2. Walk me through deriving a recurrence relation for a new problem, out loud, step by step.
3. What's the difference between top-down (memoization) and bottom-up (tabulation) — when would you pick one over the other in an interview?
4. What's the space optimization trick for 2D DP that reduces to O(n), and when does it apply?
5. If your DP solution is correct but too slow, what's your first diagnostic step?

## Week 3 Assessment Gate
- Timed mock: 2 DP problems, 50 min, must state recurrence relation out loud before coding.
- **Pass bar:** Derives recurrence without hints, correctly chooses memoization vs. tabulation with reasoning, handles base cases correctly.

## Milestone
25+ DP problems solved, can derive a recurrence relation live for an unseen problem.

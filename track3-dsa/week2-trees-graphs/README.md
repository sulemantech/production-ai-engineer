# Week 2 — Trees, Graphs, BFS/DFS

**Objective:** The second-most common category, and the one most candidates get shaky on under pressure.

## Daily Drill
- **Day 1:** Binary tree traversals — 5 problems (inorder/preorder/postorder, level order).
- **Day 2:** BST-specific — 5 problems (validate BST, kth smallest, insert/delete).
- **Day 3:** Graph BFS — 5 problems (number of islands, rotting oranges, shortest path in grid).
- **Day 4:** Graph DFS + backtracking intro — 5 problems (clone graph, course schedule/topological sort).
- **Day 5:** Backtracking — 5 problems (permutations, subsets, combination sum).
- **Day 6-7:** Mixed review set (10 problems, timed).

## Daily Interview Questions
1. When do you use BFS vs. DFS for a graph problem — what's the actual signal in the problem statement?
2. How do you detect a cycle in a directed graph vs. an undirected graph — different approaches, why?
3. What's the time complexity of your topological sort, and why?
4. Walk me through recognizing a backtracking problem — what's the tell?
5. How do you avoid revisiting nodes in graph traversal, and what breaks if you forget?

## Week 2 Assessment Gate
- Timed mock: 2 problems (1 tree, 1 graph), 45 min, explain out loud.
- **Pass bar:** Correctly identifies BFS vs DFS choice unprompted, handles edge cases (empty tree, disconnected graph) without being told to.

## Milestone
25+ problems across trees/graphs/backtracking, can identify traversal strategy from problem statement alone.

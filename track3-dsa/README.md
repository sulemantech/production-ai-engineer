# Track 3 — DSA / Algorithms Interview Prep

**Prerequisite:** [Track 2](../track2-ml-deep-learning/README.md) complete (per your sequential preference).
**Goal:** Pass live coding rounds at top-tier companies. This track is drilling-based, not build-based — repetition and pattern recognition under time pressure.
**Format:** Daily problems (pattern-focused) + daily interview-style question. Weekly Assessment Gate (timed mock round) before advancing.

---

## What to Ignore in This Track
- Obscure/rare problem types that show up in <5% of interviews — depth on core patterns beats breadth on trivia
- Competitive programming optimizations (bit manipulation tricks, advanced number theory) unless a target company specifically tests it
- Solving 500+ problems for volume's sake — quality pattern recognition on ~120-150 well-chosen problems beats brute-force volume
- Language-hopping — pick one language (Python, given your strength) and stay in it the whole track

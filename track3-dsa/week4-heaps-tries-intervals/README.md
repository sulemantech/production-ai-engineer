# Week 4 — Heaps, Tries, Intervals, Advanced Patterns

**Objective:** The "differentiator" category — less common but shows up at higher-bar companies, and signals real breadth.

## Daily Drill
- **Day 1:** Heaps — 5 problems (kth largest element, merge k sorted lists, top k frequent).
- **Day 2:** Intervals — 5 problems (merge intervals, meeting rooms, non-overlapping intervals).
- **Day 3:** Tries — 4 problems (implement trie, word search II).
- **Day 4:** Union-Find — 4 problems (number of connected components, redundant connection).
- **Day 5:** Binary search variants — 5 problems (search in rotated array, find peak element).
- **Day 6-7:** Mixed review set (10 problems, timed).

## Daily Interview Questions
1. When would you reach for a heap instead of sorting the whole array first?
2. Walk me through the merge-intervals pattern — what sort step makes it work?
3. When is a trie worth the memory overhead vs. a hash set?
4. What does union-find give you that plain DFS doesn't, for connectivity problems?
5. What's the key invariant that makes binary search work on a rotated sorted array?

## Week 4 Assessment Gate
- Timed mock: 2 problems from this week's categories, 45 min.
- **Pass bar:** Correctly picks the right data structure without being told the category, explains the tradeoff vs. the "obvious" brute force.

## Milestone
23+ problems across heaps/intervals/tries/union-find/binary search — real breadth beyond the core four categories.

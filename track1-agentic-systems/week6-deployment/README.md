# Week 6 — Production Deployment + Interview Packaging

**Objective:** Ship it. Package the whole 6 weeks into an interview-ready narrative and a live, deployed system.

## Daily Build
- **Day 1:** Deploy the capstone backend (API) to a real host. Add basic auth.
- **Day 2:** Add a minimal frontend (functional, not fancy) so it's demoable end-to-end.
- **Day 3:** Write the system design doc: architecture diagram, key decisions, tradeoffs, what you'd do differently at scale.
- **Day 4:** Prepare your 5-minute cold walkthrough (practice out loud, time it).
- **Day 5:** Mock system-design interview: design a *new* agentic system live (not your capstone) to prove generalized skill, not memorized answers.
- **Day 6-7:** Full mock interview (ideally with another human, not just me) covering technical + "walk me through a project" rounds.

## Daily Interview Questions
1. Walk me through your architecture in under 5 minutes, cold.
2. What would you change about this system if you had to support 100x the traffic?
3. What's the one decision in this project you're least confident about, and why?
4. If I gave you a blank slate, what would you build differently knowing what you know now?
5. Design (on the spot) a multi-agent system for [new scenario] — think out loud.
6. What's the hardest bug you hit across these 6 weeks, and how did you actually find it?

## Week 6 Assessment Gate
- Full mock interview: technical deep-dive + live system design + project walkthrough.
- **Pass bar:** Walkthrough is fluent with no notes, live system design shows transferable judgment (not memorized patterns), can name real tradeoffs and honest weaknesses in own work.

## Milestone (Track 1 Complete — Capstone)
Live, deployed multi-agent system with public repo, eval suite, trace/cost dashboard, documented failure-mode analysis, system design doc, and a rehearsed 5-minute walkthrough.

# Week 6 — Applied ML System Design + Interview Packaging

**Objective:** Package everything into interview-ready form — ML system design questions, not just theory recall.

## Daily Build
- **Day 1:** Practice ML system design: "design a recommendation system" — full design doc.
- **Day 2:** Practice ML system design: "design a content moderation model pipeline" — full design doc.
- **Day 3:** Evaluation metrics deep dive — precision/recall/F1/AUC, when each matters, connect to real scenarios.
- **Day 4:** Data/model drift — explain concept, design a monitoring approach.
- **Day 5:** Consolidate: build one polished artifact combining Weeks 2-5 (e.g. your transformer + fine-tuning experiment) into a shareable writeup.
- **Day 6-7:** Full mock interview: ML fundamentals + system design + walkthrough of your from-scratch work.

## Daily Interview Questions
1. Design a system that recommends products — what model, what data, what failure modes?
2. When would you optimize for recall over precision, and give a real scenario.
3. What's model drift, and how would you detect it in production without ground-truth labels?
4. Compare a from-scratch small transformer to a production LLM — what's actually different besides scale?
5. What's the biggest thing you'd get wrong if you tried to train a frontier-scale model tomorrow?
6. Walk me through your from-scratch transformer project like you're presenting it to a hiring panel.

## Week 6 Assessment Gate
- Full mock interview: ML fundamentals questions + a live system design exercise + project walkthrough.
- **Pass bar:** Fluent on fundamentals without notes, system design shows real judgment (not memorized templates), project walkthrough is confident and technically precise.

## Milestone (Track 2 Complete)
From-scratch transformer + fine-tuning experiment as portfolio artifacts, plus demonstrated fluency in ML system design and passed full mock interview.
